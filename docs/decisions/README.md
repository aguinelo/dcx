# Registro de decisões

Decisões que afetam schemas, interfaces ou escopo devem ser registradas aqui antes de orientar implementação. Identificadores e caminhos seguem a especificação do harness; texto explicativo em pt-BR.

Decisões abertas para M0:

- Schemas mínimos dos artefatos do fluxo vertical e validações semânticas.
- Formato e fronteira de acesso do `sensor_suite`.
- Regra de aprovação do verifier e classificação de issues bloqueantes.
- Provedor de modelo e configuração local de credenciais.
