# M6 — Segurança dos sensores

## Objetivo

Reduzir o acesso dos scripts de aceite ao ambiente do usuário.

## Entregue

- O runner limpa o ambiente do filho e repassa apenas `PATH`, `TMPDIR`, `LANG`, `LC_ALL`, `PYTHONIOENCODING`, `HOME` isolado e as variáveis `HARNESS_*`.
- O interpretador Python é resolvido para o executável real antes de limpar o ambiente, evitando depender de shims do shell.
- `HARNESS_SENSOR_SANDBOX=off|auto|required`; no macOS, `auto` usa `sandbox-exec` com bloqueio de rede e de escrita fora do workspace.
- `required` falha explicitamente quando o sandbox não está disponível.

## Pendente

- Sandbox equivalente no Linux.
- Limites de memória e de tamanho de saída.
- O executor e o verifier continuam dependendo do sandbox do respectivo CLI.

## Validação

- Teste do perfil confirma `(deny network*)` e `(deny file-write*)`.
- `HARNESS_SENSOR_SANDBOX=required cargo run -q -p harness-cli -- run --job-02` passa no macOS.
