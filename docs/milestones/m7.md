# M7 — Operação

## Objetivo

Tornar o dcode previsível quando um provider falha e manter a qualidade verificável em CI.

## Entregue

- `DCX_PROVIDER=auto`: Claude como primário e Codex como fallback, com erro combinado quando ambos falham.
- Workflow de CI com `fmt`, `test`, `clippy -D warnings`, `schemas --check`, `run --demo` e `run --job-02`.
- README atualizado com provedores, sandbox, ledger, apply transacional e limpeza.
- `metrics.json` por run com papel, provider, modelo, duração, tokens e custo conhecido de cada chamada; `cost_complete` indica se todos os providers reportaram custo.

## Pendente

- Empacotamento/instalação fora do workspace de desenvolvimento.
