# M7 — Operação

## Objetivo

Tornar o harness previsível quando um provider falha e manter a qualidade verificável em CI.

## Entregue

- `HARNESS_PROVIDER=auto`: Claude como primário e Codex como fallback, com erro combinado quando ambos falham.
- Workflow de CI com `fmt`, `test`, `clippy -D warnings`, `schemas --check`, `run --demo` e `run --job-02`.
- README atualizado com provedores, sandbox, ledger, apply transacional e limpeza.

## Pendente

- Custo e latência por run não são registrados como artefato.
- Empacotamento/instalação fora do workspace de desenvolvimento.
